A **skill** is, in practice, a folder containing a `SKILL.md` file: the instructions your AI agent reads and follows when you ask for a certain kind of work. It can also hold examples, scripts and reference material.

This is how agents are learning to do specific things well, such as building a website or reviewing its quality, instead of giving generic answers every time.

## Where they work
According to the documentation of the projects we follow, the same format is read by several agents: Claude Code, Codex, Cursor, Gemini CLI, OpenCode, Copilot and others. Only the install folder changes.

## What to check before installing one
A skill is a set of instructions your agent carries out, and some make it run builds and scripts on your computer. The advice from the [/awwwards]({% include url-ref.html ref="awwwards-skill" %}) project is simple: **read the `SKILL.md` before installing**, as you would with any code you run.
